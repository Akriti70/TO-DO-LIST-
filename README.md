# ✨ To-Do List React App

A modern and responsive **To-Do List application** built using React and Vite.

This project allows users to:
- ✅ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 Track total number of tasks
- 🎨 Enjoy a clean and modern UI design


## 🚀 Features

- React functional components
- React Hooks (`useState`)
- Component-based structure
- Responsive design
- Modern gradient UI
- Task management system


## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- HTML5
